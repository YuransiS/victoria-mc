## 📌 Як додавати нові кейси

Всі кейси централізовано підключаються через файл:
👉 `src/data/cases.ts`

1. Завантажте нові фотографії у папку `public/cases/` (наприклад `client3_before.jpg`, `client3_after.jpg`, `client3_review.png`).
2. Додайте новий об'єкт у масив `REAL_CASES` у `src/data/cases.ts`:
```ts
{
  id: "03",
  name: "Ім'я",
  niche: "Ніша / Професія",
  beforeImg: "/cases/client3_before.jpg",
  afterImg: "/cases/client3_after.jpg",
  reviewImg: "/cases/client3_review.png",
  beforeDesc: "Опис до...",
  afterDesc: "Опис після...",
  highlightResult: "Ключовий результат"
}
```
3. Всі лендінги та компоненти автоматично підтягнуть новий кейс.
